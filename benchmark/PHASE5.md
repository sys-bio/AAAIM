## Questions and scope

Hypotheses: identifier loss will impair chemical constraint retrieval more than text retrieval that retains names; erroneous identifier bundles may be more damaging than removal; ancestor replacement may affect methods differently and can be masked by retained direct KEGG-compound annotations. Primary comparisons are paired clean-versus-degraded Recall@1 and Recall@10 for the four locally recomputed retrieval methods; secondary R@3/5/100, MRR@10/100, empty candidate rate, reference absence from Top-10, candidate counts and timing. No presumed winner or new biological judgments.

Use exactly the 163 validation reactions already covered by Phase 3C, not all 969 validation reactions. Frozen validation-only queries and sample IDs define eligibility; labels are joined from the existing 163-row reference join after rankings freeze. Use only participating species from these validation models; do not open mixed-split reaction CSVs or the held-out split. No training data are needed because nothing is fitted. The pilot/audit have informed development and are not independent evaluation. Human judgments do not enter perturbations, fitting, policy selection or metric labels.

## Perturbations, units and fixed replicates

A species annotation bundle is the distinct ChEBI terms and direct KEGG compound IDs displayed in the frozen retrieval query for one species. An annotated sampling unit is a participating species with at least one such ID. Preserve all names, species IDs, compartment/role information, stoichiometry, equation text and reversibility. Removal removes identifiers, not all participant information. Multiple IDs are removed together for a selected bundle.

Random removal at 10%, 25%, 50%, 75%: independently per query, sort eligible species by SHA-256(seed, model, reaction, species), remove round-half-up(fraction * eligible_count) bundles. Use seeds 20261106, 20261107, 20261108. This creates nested masks across levels within each seed. Shared species may be changed differently in different reactions: this is deliberately a reaction-local information stress test, not a globally modified SBML model. Report rounding effects, realized species-bundle and identifier-link rates, unchanged queries and zero-eligible queries.

One-sided removal: separately strip all annotated reactant bundles and all annotated product bundles, one deterministic replicate each. Use the recorded SBML left/right designation even for reversible reactions; do not infer biological direction. A species on both sides loses its whole query-level bundle when selected on either side; report this overlap. A side with no eligible annotated species is unchanged/ineligible, never silently dropped from the paired denominator.

Ancestor replacement: one deterministic replicate; replace each ChEBI term having an immediate frozen is_a parent with its numerically smallest immediate parent (distance exactly 1). No lookup by target/reference reaction or retrieval success. Retain direct KEGG annotations and all other evidence, report replacements masked by direct IDs, missing/root terms, unchanged terms and replacement collisions. Load only the existing local frozen chebi_parent_map.json.gz; no downloads.

Synthetic wrong mappings: three seeds as above, target 25% of annotated query-local species, rounded as above. For each selected species choose one ChEBI sibling sharing an immediate is_a parent with an original ChEBI, possessing a nonempty local ChEBI-to-KEGG map disjoint from the union of original direct and directly mapped compound IDs. Exclude original IDs; seed/hash-order remaining siblings, choose the first. Replace the whole ChEBI bundle by that sibling and replace any original direct KEGG bundle by the chosen sibling's compounds, preventing original-ID survival through a second namespace. If no eligible sibling exists, record an unchanged/ineligible selected attempt; do not refill or use reference labels. This guarantees inconsistency with the original mapping under these constraints, not biological falsity or expert-established plausibility. Report as synthetic constrained sibling corruption, not real annotation error.

Total fixed conditions: clean once, 12 removal variants, 2 one-sided variants, 1 ancestor variant, 3 wrong-mapping variants = 19 * 163 aligned query conditions. No additional perturbation tuning, dose search or method expansion after results.

## Recomputed methods and cache contract

Rebuild the query from each perturbed record using the original query template; clean reconstructed queries must match frozen query bytes. Recompute mapping and strict rule-based candidate generation/scoring, BM25, trained bi-encoder queries, and depth-100 equal-weight RRF (k=60). Use the fixed 12,312-document catalog and fixed encoder/tokenizer/checkpoint, CLS pooling, L2 normalization, max_length=256. Document vectors may be computed once for the unchanged catalog; query embeddings and rankings must use actual perturbed query text. Exact-query/settings caches may deduplicate byte-identical requests only, never relabel clean rankings as degraded results.

Rule-based control uses the existing core strict filter and heuristic scorer, default cofactor handling, spectators=False, include_exchange=False, evaluate_candidates=True, strict_errors=True, no iterative ontology expansion or EM. Direct ChEBI-to-KEGG and direct compound evidence are rebuilt for each query. This is an explicitly bounded strict-rule control, not a claim to reproduce the historical Phase 2 ontology-relaxed workflow. Drop unconstrained all-catalog matches as nonretrieval, retain empty cases in denominators. Check recomputed clean BM25/encoder/fusion against frozen same-query rankings and disclose any differences before making historical comparisons. Only paired recomputed clean/perturbed results support robustness claims.

The existing iterative ontology-relaxation workflow is not added to the full grid because it is a distinct, substantially more expensive configuration; defer it as an optional extension. Direct LLM outputs and grounded outputs cannot be reused after query/evidence/config changes. Prepare grounded payloads over newly recomputed evidence, compare complete canonical payload identity to clean requests, and report valid reuse versus missing paid outputs. No new LLM predictions or end-to-end degraded accuracy are produced.
