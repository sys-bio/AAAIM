# MODEL2501150001 annotation report

Run date: 2026-09-15  
Outcome: Table S3 substantially improves complex recovery; EGF remains a systematic entity-routing error.

## Model and evaluation

This EGFR–ERK signaling model has **47 species and 51 reactions**. Both runs used `gpt-5-mini-2025-08-07`, direct retrieval with `top_k=3`, final `n_return=1` per species or complex component, automatic entity typing, ChEBI + UniProt, and human taxonomy (`9606`). Table S3 was withheld from the SBML-only run and supplied to the augmented run. The 46 SBML species aligned to Table S3 were scored by their unique biological components; Table S3 also contains one species absent from the SBML, while the SBML has standalone `GRB2` absent from Table S3.

| Condition | Species with candidates | Complete species | Components recovered |
|---|---:|---:|---:|
| SBML only | 47/47 | 23/46 (50.0%) | 90/113 (79.6%) |
| SBML + Table S3 | 47/47 | 41/46 (89.1%) | 108/113 (95.6%) |

## Wrong top-1 predictions

- SBML only: `mEL` and `mELmEL` predict ChEBI `CHEBI:140739` (Glu-Gly-Phe) for the EGF component. `EG2SOS` adds GRB2 although the literal Table S3 description lists EGF–EGFR–SOS, not GRB2.
- SBML + Table S3: `mEL`, `mELmEL`, `E`, `EG2`, and `EG2SOS` all predict `CHEBI:140739` for EGF. The intended component is human EGF, UniProt `P01133`.

The augmented run's only five missing reference components are the same five EGF failures. The SBML-only run additionally misses EGF in three of these species and GTP in 18 RAS–GTP-bound complexes.

## Issues for further review

- EGF is being routed as a chemical despite explicit protein context. This must be fixed before accepting these annotations; top 3 would not correct a wrong database route.
- Family labels (`RAS`, `MEK1/2`, `ERK1/2`, `SOS1/2`) deliberately yield one top identity per component. A later top-3 sensitivity run could measure paralog-family recall, but it should not replace top 1 as the primary result.
- Confirm whether inhibitor-bound species should include sorafenib as a separate component and whether standalone `sorafenib` denotes the free compound rather than a salt formulation.
