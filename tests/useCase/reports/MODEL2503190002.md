# MODEL2503190002 annotation report

Run date: 2026-09-15  
Outcome: all molecular species have a supported top-1 identity (except process states).

## Model and evaluation

This DNA-damage-response model has **31 species and 40 reactions**. The run used `gpt-5-mini-2025-08-07`, direct retrieval with `top_k=3`, final `n_return=1` per species or component, automatic entity typing, ChEBI + UniProt, and human taxonomy (`9606`). Predictions were checked against the publication, supplement, and canonical human identifiers because the SBML has no element-level reference identifiers.

| Measure | Result |
|---|---:|
| Species with candidates | 28/31 |
| Molecular species with complete supported top-1 identities | 28/28 (100%) |
| Process/state species left without identifiers | 3/3 |

The `PP2A_I2PP2A` complex returns one correct identity for each component (`PPP2CA` and `SET`). PUMA emits two UniProt accessions, but both belong to the same top-ranked `BBC3` identity and therefore do not violate top 1.

## Wrong top-1 predictions

None among the 28 molecular species. `DNA_damage`, `Autophagy_active`, and `Autophagy_inactive` correctly have no molecular identifier.

## Issues for further review

- `PP2A` and `CK2` are families/complexes, while the output selects representative catalytic subunits (`PPP2CA` and `CSNK2A1`). This is semantically defensible but should be stated in the manuscript.
- A top-3 run is not needed for the primary evaluation. It would only be useful later as a sensitivity analysis for family/subunit coverage.
